# Pinboard Studio

Pinboard Studio is a visual idea canvas for collecting, organizing, and connecting project ideas, notes, references, links, and concepts.

## Features

- Drag-and-drop idea cards
- Visual board layout
- Filtering and sorting
- Detail modal
- Related idea connections
- Responsive frontend
- Laravel backend structure

## Tech Stack

- React
- TypeScript
- Vite
- Laravel
- SQLite

## Run Frontend

```bash
cd frontend
npm install
npm run dev
